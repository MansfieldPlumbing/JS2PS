# Experiments

These scripts record exploratory parser observations. They are not release gates and may demonstrate rejected ideas, accidental parses, or incomplete hypotheses.

`legacy` contains early observations retained for provenance. Their output must not be interpreted as a current compatibility claim.

`legacy/Probe-QuickPSSemantics.ps1` and `legacy/SEMANTIC-MATRIX.md` record hand-asserted semantic classes (for example `NATIVE-EQUIVALENT`) that no executable case measured. They are kept as provenance only and must not be read as semantic support.
